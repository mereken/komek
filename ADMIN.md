# Админ-панель Komek

Страница `/admin` для администраторов: сводка (дашборд), пользователи, заказы.

- **Сводка:** число пользователей, заказчиков и исполнителей, заказов и откликов, сумма выполненных заказов, средняя оценка, заказы по статусам, график за 14 дней.
- **Пользователи:** список, поиск по имени, телефону и e-mail, удаление.
- **Заказы:** список, фильтр по статусу, отмена и удаление.

## 1. Какие файлы куда

Копируйте с теми же путями (в `komek v3`), файлы с пометкой «заменить» перезаписывают существующие.

| Файл | Действие |
|---|---|
| `backend/.../model/User.java` | заменить (добавлено поле `is_admin`) |
| `backend/.../dto/UserDto.java` | заменить |
| `backend/.../dto/AdminDtos.java` | новый |
| `backend/.../service/AdminService.java` | новый |
| `backend/.../web/AdminController.java` | новый |
| `backend/.../web/UserController.java` | заменить |
| `backend/.../web/HealthController.java` | новый (если его ещё нет с прошлого шага) |
| `backend/.../security/JwtAuthFilter.java` | заменить |
| `backend/.../security/SecurityConfig.java` | заменить (**заменяет** версию из прошлого архива) |
| `frontend/src/api.ts` | заменить |
| `frontend/src/App.tsx` | заменить |
| `frontend/src/pages/Profile.tsx` | заменить |
| `frontend/src/pages/Admin.tsx` | новый |
| `frontend/src/admin.css` | новый |

`...` в пути = `src/main/java/com/komek`.

## 2. Выложить

```bash
git add .
git commit -m "Add admin panel"
git push
```

Render и Vercel пересоберутся сами. При первом запуске бэкенд сам добавит колонку `is_admin` в таблицу `users` (для всех существующих пользователей значение `false`). Дождитесь на Render строки `Started KomekApplication`.

## 3. Сделать себя администратором

Админом нельзя стать через сайт, только через базу.

1. Зарегистрируйтесь на сайте (или войдите под своим пользователем).
2. Neon → ваш проект → **SQL Editor**:
   ```sql
   SELECT id, full_name, email, phone, is_admin FROM users ORDER BY id;
   ```
3. Найдите свою строку и выполните (подставьте свой `id`):
   ```sql
   UPDATE users SET is_admin = true WHERE id = 1;
   ```
4. Обновите страницу сайта (F5). В **Профиле** появится кнопка «Админ-панель». Либо откройте `https://ВАШ-САЙТ.vercel.app/admin`.

Снять права: `UPDATE users SET is_admin = false WHERE id = 1;`. Действует сразу, роль проверяется в базе при каждом запросе.

## 4. Что важно знать

- **Удаление пользователя** удаляет также его заказы, его отклики и задания, где он был исполнителем (у других заказчиков такие заказы тоже исчезнут). Это необратимо, перед удалением сайт спрашивает подтверждение.
- Нельзя удалить самого себя и других администраторов. Чтобы удалить администратора, сначала снимите ему `is_admin` в базе.
- «Отменить» переводит заказ в статус «Отменён» (для выполненных и уже отменённых недоступно). «Удалить» убирает заказ и отклики совсем.
- Все запросы `/api/admin/*` проверяются на сервере: обычный пользователь получит отказ, даже если откроет адрес вручную.
- Удалённый пользователь автоматически «выходит» из приложения при следующем действии.

## 5. Если что-то не работает

| Симптом | Что проверить |
|---|---|
| Сборка на Render упала | Пришлите последние строки лога: Java-код я не мог скомпилировать в своей среде. |
| `/admin` сразу возвращает на главную | У пользователя `is_admin = false`, либо страница открыта до выдачи прав: обновите её (F5) или выйдите и войдите снова. |
| Ошибка про колонку `is_admin` | Бэкенд на Render ещё не обновился (проверьте Events и Logs) или упал при старте. |
| Пустые цифры или ошибка «Что-то пошло не так» в админке | Бэкенд мог уснуть, подождите минуту и нажмите «Обновить». Иначе посмотрите Logs на Render. |
